# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

## [0.4.1] - 2025-11-18

### Changed
- Improved documentation website with custom icons and accurate feature descriptions
- Refactored table name inference to format-specific implementations for better maintainability
- Optimized CI pipeline by combining build, test, and coverage into a single job
- Enhanced Dependabot configuration for comprehensive dependency monitoring
- Updated dependencies to latest versions

### Added
- E2E test coverage reporting flag in CI pipeline
- Improved Codecov integration in CI/CD pipeline

### Fixed
- Corrected format driver count claims in documentation (now accurately reflects ~12 supported drivers)
- Removed unverified performance claims from website
- Upgraded Codecov orb to v5.4.3 for better reliability

## [0.4.0] - 2025-11-08

### Added
- SQL query support with custom table names
- Comprehensive release blog post for v0.4.0
- Documentation overhaul with improved structure

### Changed
- Removed promotional content to establish single source of truth in documentation
- Enhanced documentation organization and clarity
